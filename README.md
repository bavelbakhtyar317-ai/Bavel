# PixelVault - Game Store

A static game store website (HTML, CSS, JavaScript). No build step needed.

## Publish on GitHub Pages
1. Create a new repository on github.com (e.g. `game-store`), set it to Public.
2. Click **Add file > Upload files**, drag in `index.html`, `style.css`, `script.js`, `README.md`, then **Commit**.
3. Go to **Settings > Pages**.
4. Under **Branch**, choose `main` and `/ (root)`, then **Save**.
5. After about a minute your site is live at `https://YOUR-USERNAME.github.io/game-store/`.

## Customize
- Games and prices: edit the `games` list at the top of `script.js`.
- Colors: edit the `:root` variables at the top of `style.css`.
- Store name: search for "PixelVault" in `index.html`.
